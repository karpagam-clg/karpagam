Bomb Game:
This is a simple Bomb Game made using Java.

About the Game:
In this game, there are hidden bombs and safe positions. The player has to choose positions without selecting a bomb.
The player gets 3 lives. If a bomb is selected, one life is lost and the player can continue if they still have lives remaining.
To win the game, the player must select all the safe positions without selecting any bomb.
Lives

The player starts with 1 life.
Safe choice = Continue
Bomb = Lose 1 life
Lives reach 0 = Game Over
All safe positions selected = Win
Point System
The player gets points for every safe position they choose.
For example:
Safe choice = +1 points
Bomb = Lose 1 life
The final score is displayed at the end of the game.

Concepts Used:
Array - for storing data in the form of Matrix 
Set     - Used for storing bomb locations 
If/else  -  for checking conditions 
For Loop - for matrix traversal 
While Loop – runs until any player wins (no bomb  condition)

Goal:
The goal of the game is to find all the safe positions and win the game while avoiding the bombs.
The player has 1 life (3 lives obtainable), so they can make mistakes, but they must eventually clear all the safe positions to win.
